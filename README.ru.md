# podkop-sub

Импортирует VLESS-ссылки из подписки в секцию [podkop](https://github.com/itdoginfo/podkop)
на OpenWrt (через SSH и `uci`). Меню в терминале со стрелками, работает в Termius,
MobaXterm и обычном Linux-терминале. Языки: русский и английский.

- Показывает серверы со страной, городом и флагом, вы выбираете, какие записать.
- Проверяет доступность: задержка через `podkop clash_api`, новые ссылки из подписки
  проверяются до записи (TCP, затем полная проверка Reality через sing-box).
- Защищённые ссылки: скрипт их никогда не удаляет, не заменяет и не обновляет.
- Синхронизация по расписанию (`/etc/cron.d`): добавляет новые, удаляет пропавшие, заменяет
  мёртвые, применяет через `reload` с проверкой. Необязательные уведомления в Telegram.

English version: [README.md](README.md).

## Установка (Debian 12/13 или Ubuntu, от root)

    git clone https://github.com/<you>/podkop-sub.git
    cd podkop-sub
    sh install.sh            # ставит в /opt/podkop-sub, команда podkop-sub
    podkop-sub               # первый запуск откроет мастер настройки

`install.sh` пытается скачать sing-box (нужен для полной проверки Reality). Если не получилось,
проверка идёт только по TCP. Бинарник можно положить вручную в `/usr/local/bin/sing-box`.

## Доступ к роутеру

Мастер создаёт отдельный ключ ed25519 и показывает команду для роутера:

    echo 'ssh-ed25519 AAAA… podkop-sub' >> /etc/dropbear/authorized_keys
    chmod 600 /etc/dropbear/authorized_keys

Нужен root: на OpenWrt менять `/etc/config` могут только root-пользователи. Ключ можно
ограничить `from="IP-этого-хоста"` в authorized_keys.

## Меню

- **Обновить ссылки из подписки**: выбрать ссылки, действие (заменить / добавить / слить),
  посмотреть изменения, записать, применить.
- **Ссылки на роутере**: показать, проверка доступности, удалить, добавить свою ссылку,
  проверить новые ссылки из подписки без записи, бэкапы и откат.
- **Podkop**: статус, перезапуск, reload, лог.
- **Расписание**: статус, включить или изменить, отключить, запустить сейчас (пробный или полный),
  лог.
- **Настройки**: подписка, роутер, секция, типы ссылок, страны-исключения и предпочтения,
  защищённые ссылки, параметры синхронизации, Telegram, эмодзи-флаги, язык, мастер.
- **Справка**: клавиши, шаги синхронизации, флаги командной строки и коды возврата.

Клавиши: ↑↓ и Enter; пробел отмечает в списках; `a` все, `i` инверсия; Ctrl+C — шаг назад.

## Командная строка

    podkop-sub --list                 # подписка с учётом фильтров
    podkop-sub --check                # доступность ссылок на роутере
    podkop-sub --check-sub            # новые ссылки из подписки: TCP / Reality, ничего не пишет
    podkop-sub --sync --dry-run       # что сделал бы запуск по расписанию
    podkop-sub --sync                 # сам запуск по расписанию (cron)
    podkop-sub --update --action merge [--only-preferred] [--restart]
    podkop-sub --rollback

## Синхронизация подробно

1. Скачивает подписку (3 попытки), применяет фильтры.
2. Проверяет ссылки роутера через `podkop clash_api get_proxy_latency`. Узлы sing-box
   сопоставляются по хосту, порту и SNI, а не по номеру.
3. Проверяет кандидатов из подписки до записи: сначала TCP, затем полная проверка Reality
   временным sing-box, если он установлен. Лимит за запуск: `sync.probe_max`.
4. План: добавляет новые ссылки (только страны-предпочтения, если они заданы, как в ручном
   меню); удаляет пропавшие из подписки (можно выключить); мёртвую ссылку заменяет свежей,
   которая отвечает. Защищённые ссылки не трогаются.
5. Изменений нет: завершается. Активный узел не отвечает, а живой есть: переключает без
   перезапуска.
6. Иначе: бэкап, запись, `podkop reload`, проверка, что sing-box работает именно с записанным
   списком (запасной вариант — restart), повторная проверка доступности.
7. Отчёт в Telegram, если настроено.

Коды возврата: `0` успех или изменений нет; `1` ошибка подписки или роутера (список не менялся);
`2` записано, но не применено; `3` защищённый список ещё не настроен.

## Telegram

Настройки → Telegram: токен бота (@BotFather) и chat id, есть тестовое сообщение.
Уведомления: список изменён, переключён активный узел, ошибки (об ошибке подписки — после
N неудач подряд, по умолчанию 3).

## Конфиг и безопасность

`~/.config/podkop-sub/config.toml` создаётся с правами 600: в нём ссылка подписки с токеном.
Ключ `id_ed25519` тоже закрытый. Эти файлы нельзя публиковать и коммитить.

## Тесты

    python3 -m unittest discover -s tests -t .

Тесты используют фейковые `ssh`, `uci`, `podkop`, `/etc/init.d/podkop` и sing-box (tests/fakebin)
и заглушку questionary. Реальный роутер они не заменяют: перед включением расписания сравните
`podkop-sub --check` с N/A в LuCI и запустите `podkop-sub --sync --dry-run`.
